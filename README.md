## 🚀 Quick Start (Local Run)

### 1. Install dependencies
```bash
npm install
```

### 2. Start development server
```bash
npm run dev
```

The app will start at `http://localhost:5173`.

### 3. Build for Production
```bash
npm run build
```

## ⚡ Deployment to Vercel

### Option 1: Deploy via GitHub (Recommended)
1. Push this folder to a GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio commit"
   git branch -M main
   git remote add origin https://github.com/princessazucena/princess-portfolio.git
   git push -u origin main
   ```
2. Log into [vercel.com](https://vercel.com).
3. Click **Add New Project** → **Import** your repository.
4. Framework Preset: **Vite** (auto-detected).
5. Click **Deploy**. Vercel will build and assign your live URL in seconds!

### Option 2: Deploy directly via Vercel CLI
```bash
npm i -g vercel
vercel
```
Follow the prompt instructions, and your site is live immediately!
